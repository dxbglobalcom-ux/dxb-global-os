# PLAN FIXTURES — the plans the ruler breaks itself against

Each file here is a PLAN (SKILL.md, Layer 2) that is either sound or broken in exactly one way.
They live inside the engine so that a COPY of the engine carries them: `tests/b46/research-ruler.ts`
runs the copy's own `scripts/plan.py` against these files, so a repair that weakens the plan gate
is caught on the copy before it reaches the engine.

Every broken fixture was a REAL defect, measured on 2026-09-20 on the CEO's own complaint.
