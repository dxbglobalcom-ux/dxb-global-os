## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CEO's .env → git index | the only file ever holding real values must be structurally unable to enter version control |
| vault file → agent context | agent tool reads cross from disk into model context/transcripts; the vault must be denied at the tool layer |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Information Disclosure | .env committed to git | critical | mitigate | .gitignore rules (Task 1) + ls-files gate + gitleaks pre-commit hook from plan 01-01 as second layer |
| T-01-06 | Information Disclosure | agent reads .env into model context | high | mitigate | permissions.deny Read rules + A8 functional spot-check with harmless marker (Task 2); no real .env exists until the CEO fills it in Wave 2+ |
| T-01-07 | Spoofing | realistic-looking placeholder mistaken for / replaced by a real value | low | mitigate | only the literal __SET_ME__ placeholder permitted; grep gate proves every non-comment line matches |
| T-01-08 | Tampering | settings merge clobbers existing project config | medium | mitigate | read-then-merge with key preservation; acceptance criterion checks prior keys survive |
