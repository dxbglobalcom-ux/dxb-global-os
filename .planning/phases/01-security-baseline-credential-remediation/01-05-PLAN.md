|----------|-------------|
| original .odt → executor context | the original holds the leaked credentials; content must never cross into agent context, logs, or evidence |
| sanitized copy → git history | once committed it is permanent and clonable; must be proven clean at markdown and container level first |
| local disk → cloud sync/trash | copies of the original outside the repo are an invisible re-leak vector |
