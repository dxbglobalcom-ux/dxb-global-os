  <action>
    Create `scripts/hooks/pre-commit` as a POSIX sh script and `chmod +x` it. The script must, in order: (1) prepend `$HOME/.local/bin` to PATH so gitleaks resolves for every git client regardless of login-shell PATH (parallel Wave-1 executor agents commit through this hook too); (2) if `command -v gitleaks` fails, print an error to stderr saying the scanner is missing and the commit is blocked, then exit 1 — fail closed, a missing scanner must never let a commit pass (RESEARCH Pitfall 7); (3) otherwise exec `gitleaks git --pre-commit --staged --redact --verbose` — the `--redact` flag is mandatory so hook output never prints a matched value (CEO no-values rule). Note: `gitleaks git` is the current v8.19+ command form; the older detect/protect subcommands are deprecated (RESEARCH "State of the Art"). Add a header comment documenting the clone-bootstrap requirement: fresh clones must run `git config core.hooksPath scripts/hooks` once.

    Activate the hook: run `git config core.hooksPath scripts/hooks`.

    Self-test protocol (proves the hook FIRES, not just exists), in order: (a) generate a synthetic canary line assigning a fresh random 40-hex value (from `openssl rand -hex 20`) to an AWS-style secret variable name — the value must be freshly random, never a real or previously seen credential; (b) prove gitleaks detects that line via stdin mode (pipe the line into `gitleaks stdin --redact`) — expect a non-zero exit; if it is NOT detected, adjust the canary to a pattern the default rulepack flags (e.g. a generic api-key assignment with higher-entropy value) before proceeding; (c) write the line to `canary-selftest.txt` at repo root, `git add canary-selftest.txt`, attempt a `git commit` — the hook MUST block with non-zero exit; (d) clean up with the scoped commands `git restore --staged canary-selftest.txt` then `rm canary-selftest.txt` — never use bare `git reset` (parallel Wave-1 plans may have their own staged files in this shared repo).

    Create the evidence dir with `mkdir -p` and write `evidence/hook-selftest.md` recording: UTC timestamp (`date -u`), gitleaks version, stdin-mode exit code, blocked-commit exit code, one redacted output line proving the block, and confirmation the canary file was removed. Status codes and redacted lines only — no canary value in the evidence file.
  </action>
  <verify>
    <automated>test -x scripts/hooks/pre-commit && git config core.hooksPath | grep -qx 'scripts/hooks' && test -f ".planning/phases/01-security-baseline-credential-remediation/evidence/hook-selftest.md"</automated>
  </verify>
