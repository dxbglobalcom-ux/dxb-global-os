## 1. F032 — the chain whole from zero, and the ruling inside it

Three separate breaks, each measured, each fixed at its source:

**(a) The department was never born.** `20260903001000_b43_media_studio_department.sql` inserted the
department with a SET-RETURNING select against `companies`; the holding company row is born in
`db/seed/20260711_holding_core.sql`, and the seed runs after the whole chain. On an empty database the
select returned zero rows, the department was not created, and the file died on its first employee:

```
log:238 [bootstrap] applying 20260903001000_b43_media_studio_department.sql
log:239 ERROR:  insert or update on table "agents" violates foreign key constraint "agents_department_fkey"
log:240 DETAIL:  Key (department)=(media-studio) is not present in table "departments".
```

Fixed with the house's own idiom (`20260712014000_org_mutations_e63.sql` does exactly this for the other
departments): a **scalar subquery**, so the row is born with `company_id NULL` on a bare chain and the
seed's own `UPDATE departments SET company_id = … WHERE company_id IS NULL` binds it afterwards. Both live
engines recorded this version on 2026-09-03 and skip the file by version (`bootstrap-db.sh` compares
versions, never contents), so the correction changes nothing that has already run.

**(b) The app role could not write the platform's own event row.**

```

        CONTEXT:  SQL function "send" statement 1
```

`scripts/bootstrap/preamble.sql` creates the `realtime.messages` stub on the ADMIN plane
(`DXB_PSQL_ADMIN`), so on a database where the platform's realtime init has never run the table belongs
to the admin role and the app role cannot insert — and `fn_hr_create_employee` emits an event through
`realtime.send()`. Ownership + the grants a live Supabase database gives were added **inside the
creation guard**, the same parity act the file already performs for the migration ledger. A live
database never enters that branch (measured below).

self-skips on a bare catalogue exactly as its sibling `20260903190000` does, and its guarantee counts
what the engine actually carries instead of a number that assumes a seeded machine.
