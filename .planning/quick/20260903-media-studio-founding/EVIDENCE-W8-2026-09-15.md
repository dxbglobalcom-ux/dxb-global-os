## The four defects, and what each one actually was

**F049 — the suite wrote into the holding's production directory.** `media.ts` had
`export const MEDIA_WORK_ROOT = process.env.DXB_MEDIA_WORK_ROOT ?? "/home/dxb/tools/h3/jobs"` — evaluated at IMPORT.
Both b43 suites set that variable in `beforeAll`, which in ESM always runs after imports resolve, so the redirect
never took effect. Every run since B43 was born (2026-09-03) wrote probe frames into the real work root.
`media-lane.ts`'s `MEDIA_PATHS` had the same shape. Both read at call time now (a function, and getters).

```
probes BEFORE a full run: 105      vitest run tests/b43 → 8 files, 70 passed      probes AFTER: 105   (delta 0)
```

**F022 — a cancellation was recorded as a failure.** `stopScoped` waits up to 10 s for the child to die, so the
child's own `close` event always settled the promise first, with `"<cmd> exited null: …"`. Job `16277dac` carries
`cancel_requested=t`, `status=failed` and exactly that error. The reason for the kill (`killedFor`) is now set
before the kill lands, and the `close` handler honours it — whichever wins the race tells the same story.

**F023/F026 — nothing gave back a job a dead process was holding.** A claimed job is `running`, and the running
process is the only thing that would finish it. `recoverOrphanedMediaJobs()` now runs before the lanes look for
work: at that moment this process holds nothing, so a row still `running` is an orphan by definition. Ordered work
goes back to `queued`; work already being cancelled lands `cancelled`; the move is audited as `media.recovered`.
The log names the lane that held it (read in the same statement, because `RETURNING` sees the new row and the one
value a person needs is the one being erased).

**F047 — the stop timeout.** The unit had NO `TimeoutStopSec` line, so systemd's 90 s default applied while a shoot
take runs ~14 minutes. Now `TimeoutStopSec=20min` in `scripts/systemd/dxb-scheduler.service`, installed and live.

```
TimeoutStopUSec: 1min 30s  →  20min
daemon started after the unit file changed: +4 s      after the outbox-executor build: +21 s
```
