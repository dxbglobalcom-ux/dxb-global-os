He brought a prompt from a post (author not found, 2026-11-02 search) and asked for different site styles

## The design

1. **A style drawer in the Web-Studio's cupboard.** Each style is one short card (~2 KB: principles,
   references, signature moves, checks). The default card is the house style — showy, luxurious, wow
   (ScrollCraft and its house rule 4).
2. **The first new card: Precision.** Every screen has one purpose and one primary action · the screen
   explains itself; when it needs a tagline or helper text to make sense, the layout is fixed instead ·
   the product is the hero: the real screen, real data · every detail finished (type scale, alignment,
   motion, dark and light) with the dxb-design skills (Emil Kowalski's, Apple design) · every decision
   raises the user's, the developer's and the agent's experience together without breaking anything — the
   agent half is the holding's edge (Linear itself now says "for teams and agents").
3. **The prompt's flaws are fixed in the card.** Text that covers a layout's gap goes; field labels,
   accessible names, legal text and error messages stay (accessibility is not plainness — rule 4). The
   prompt has no measure; the card's checks are it (5).
4. **When it opens.** The master never chooses it. The brief has a style field, default the house style;
   Precision opens only when the client or the CEO asks for it in their own words, quoted in the brief.
   The card is a drawer file read when the brief names it, never a self-triggering skill (a client's
   "make it clean" must not open it). The card is written in its own words; no banned word enters a skill.
5. **Checks before delivery.** A fresh eye that has not read the brief names each screen's purpose and
   primary action in five seconds · every line of text on a screen is classed; a decoration line goes or
   the layout is fixed · accessibility scan: zero serious violations; the primary task done by keyboard
   alone · speed: Google's Core Web Vitals "good" on a phone · an agent completes each screen's primary
   task by accessible names only · the wow check stands: the art director and his eye; an empty-looking
   page is a defect — fewer elements means more craft per element.
6. **Where it is used.** Sites, web apps, mobile apps and the systems built for clients; the screens of
   Nate Herk's systems (the company brain's ask screen, the voice note's sign-off screen) fit it. It sits
   in the Web-Studio; any job that builds an interface opens it.
7. **New styles.** No catalogue written in advance. When a client says "like that site", the studio
   measures the site (type, colour, spacing, motion) and writes a new card from it — the principles, never
   the content or the brand.
8. **When it is written.** The design goes into the web office plan (two writers, Sol, once to him). The
   card is written with the web office build; its first test is a demo — the company brain's landing page
   and ask screen in Precision — judged by his eye, and kept as the clients' style sample.
