## The spec the builder receives (fixed before the work)

- File `~/.claude/hooks/dxb-context-gate.py`, stdlib only, wired in `~/.claude/settings.json` on two
  events: `UserPromptSubmit` (every prompt) and `PreToolUse` with matcher `Agent|Task`.
- Reads the record the status line already writes for THIS session:
  `$XDG_RUNTIME_DIR/claude-ctx/<session_id>.json` (`/tmp/claude-ctx` without XDG, the code gate's
  rule), field `used_pct`. `session_id` comes from the hook's stdin JSON.
- **His numbers, 2026-09-21, in one place:** `RED_LINE_PCT = 40`, `AGENT_DENY_PCT = 45`.
- At `used_pct ≥ 40`, on `UserPromptSubmit`: stdout JSON `hookSpecificOutput.additionalContext` =
  `🔴 CONTEXT N% — hand over at the first clean break (dxb-team1 §5 / dxb-crew §3): no battery
  running, tree committed, report sent; then the handover note and the successor session through
  operator (dxb-crew §4). At 45 % the Agent tool is refused.` Below 40: no output at all.
- At `used_pct ≥ 45`, on `PreToolUse` for `Agent` / `Task`: `permissionDecision: "deny"` with a
  reason that names the number and the exit (commit · handover note · successor through `operator`,
  dxb-crew §4). Below 45: no output. Any other tool: no output.
- **Staleness: none.** Context only grows inside a session, so an old record is a lower bound and
  still obliges (`dxb-ctx` refuses a record older than 10 min because it is read by a human who can
  take a screenshot instead; the hook has no screenshot). The record's age in seconds is logged.
- Missing record, corrupt record, `used_pct` not a number (bool included), no `session_id`,
  non-dict or empty stdin: exit 0, no stdout, no stderr, nothing logged (silent inputs, not
  failures). Any exception: traceback to `dxb-context-gate.err`, exit 0, no stdout.
- Only decisions are logged (`red-line`, `deny`), one JSON line each (`ts`, `session_id`, `event`,
  `tool`, `agent_type`, `used_pct`, `record_age_s`, `decision`) to `$DXB_CONTEXT_GATE_LOG_DIR` or
  `~/.claude/logs/dxb-context-gate.jsonl`; tracebacks to `dxb-context-gate.err`.
- Cases in `tests/hooks/context-gate.test.ts` on the code-gate harness (the real hook, spawned where
  it stands, each case in its own `XDG_RUNTIME_DIR` box).
