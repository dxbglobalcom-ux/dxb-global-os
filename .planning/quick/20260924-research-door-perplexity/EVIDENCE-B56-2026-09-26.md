**`evidence.jsonl`** — one per run, `<run>/evidence.jsonl`, rows per `schemas/evidence_row.schema.json`
(ids `L0001…`, `kind` discovery|evidence, `passage` VERBATIM from a fetched body). Appends under an
`fcntl.flock` on `<run>/evidence.lock` (seven hunters write at once). Extra fields allowed by the schema's
open shape: `platform` (from the classifier), `hunter` (role name or "ground").

**`scripts/evidence.py`** (Lane A builds; B and C call):
- `from-ground <run>` — every `<run>/ground*/*.raw` and `ground*/pages/*.md` → rows (dedupe on `url_canonical`;
  a raw that carries the post body — X `full_text`, Reddit `selftext`/comments, HN, Facebook — becomes
  `kind=evidence` with the body cached and `passage` = the body's first 600 characters; a headline-only
  hit is `discovery`). Idempotent. Prints one line per platform: `platform=<p> found=<n> body=<m>`.
- `list <run> --platform <p> [--unread] [--kind all|discovery|evidence]` — TSV `id \t url \t title \t liveness`;
  `--unread` = no cached body yet.
- `fetch <run> --url <u> [--print]` — fetches the body READ-ONLY through the skill's own readers by platform
  (X: `opencli twitter thread`; Reddit: `opencli reddit read`; YouTube: `opencli youtube transcript` +
  `comments`; the rest: `scripts/fetch.py` chain / `hidden.py read`), caches at
  `<run>/bodies/<sha256(url_canonical)>.txt`, sets the row's `bytes`, `http_status`, `liveness=alive`
  (creates the row if new); prints `OK <id> <bytes>B <cache-path>` (and the text with `--print`).
  On failure: `liveness=blocked|dead`, `notes=<error>`, prints `KAPALI KAPI <url> <reason>`, exit 3.
- `add <run> --url <u> --quote "<text>" [--author A --date D --title T]` — needs the cached body (fetches
  if missing); the quote must be a VERBATIM substring of the body under normalisation (NFKC, whitespace
  runs → one space, curly quotes → straight; case kept); success → a NEW row (one row per quote), `kind=evidence`,
  `passage`, `passage_sha256` (sha256 of the normalised passage), author/date from args or the body; prints the id.
  Failure → `REFUSED quote not in body: <url>`, exit 2, `evidence.jsonl` byte-identical.
- `show <run> <id>` — the row as JSON.

**`scripts/kapsama.py <run> [--answer <file>] [--legacy] [--format md|tsv]`** (Lane A): prints the coverage
table, one row per platform present + `web`: `Platform | Bulundu | Okundu | Cevapta | Okunmadı / kapalı kapı`.
Bulundu = distinct `url_canonical` · Okundu = distinct urls with a body (`bytes>0`, `liveness=alive`) ·
Cevapta = distinct urls among the `[Lxxxx]` ids in `--answer` · Okunmadı = `kapı kapalı: <status/reason> ×k`
(liveness blocked/dead, grouped by reason) + `denenmedi ×m` (unchecked). **Prints, never blocks:** exit 0
whatever the numbers; exit 1 only when `<run>` is missing. `--legacy` reads a pre-v2 run: Bulundu = domain
count in `sources.json` (X = x.com + twitter.com + t.co), Okundu = distinct platform urls handed to a body
reader in the hunters' `*.jsonl` tool calls (`opencli twitter thread|comments`, `opencli reddit read`,
`opencli youtube transcript|comments`, `hidden.py read`, `fetch.py`, `WebFetch`), Cevapta = distinct
platform urls in `final.md`.

**`scripts/render.py <run>/answer.md --evidence <run>/evidence.jsonl --out <run>/final.md [--no-coverage]`**
(Lane C): `[L0042]` → `[n]` (first appearance order); a "Kaynaklar" section: `n. **author** · date · platform
— “passage” — url` from the row, never from the answer; then "Nereye bakıldı" = `kapsama.py <run> --answer
answer.md` (subprocess, same dir); refuses with exit 2 and a one-line reason: an id not in the file, a raw
`http(s)://` in the answer body (R6), a `> ` quote block in the answer body (quotes come from rows only).

**`fleet/fleet.sh`** (Lane B): hunters `--model "$MODEL" --effort low` with `MODEL=claude-opus-5-5`,
`TMO=600`; after the grounds: `evidence.py from-ground "$OUT"`; each hunter's prompt carries ITS platforms,
the address list (`evidence.py list "$OUT" --platform <p> --unread`, per platform, id + url + title), the
three commands (`fetch`, `add`, `list`) with `$S` spelled out, and the one-sentence brief — *read every
address on your list; every quote you keep goes in with `add`; an address you could not read is recorded
by `fetch` (it writes the closed door), never skipped in silence; stop only when the list is exhausted

address on another platform is added the same way, it is never lost*. Hunter output (`HUNTER-<role>.md`):
one HÜKÜM line · one status line per platform `PLATFORM <p>: bulundu N / okundu M / okunmadı: <sebep> /
kapı kapalı: <hata>` · `KULLANDIĞIM SATIRLAR: L…` — no six prose blocks. `merge.py` counts only
