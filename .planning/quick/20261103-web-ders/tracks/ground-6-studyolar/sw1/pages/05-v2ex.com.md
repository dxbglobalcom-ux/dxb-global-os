  content: "最近 [Vokie]( https://vokie.com/) 官网被一些朋友夸了（我觉得审美这东西是各有喜好的，喜欢的朋友谢夸），很多朋友也好奇：设计参考都是从哪里找的？所以，我也想发一个帖子分享一下。\r\n\r\n**👉 vokie.com**\r\n\r\n![Vokie 官网首屏]( https://i.imgur.com/YlJGdL9.jpeg)\r\n\r\n我清理了一遍收藏夹，最后留下 12 个比较常用的网站。先说一个可能有争议的感受：\r\n\r\nAwwwards 很适合打开脑洞，但真要落到产品页面上，Mobbin 、Refero 这类真实产品库往往更实用。\r\n\r\n我的使用顺序一般是：\r\n\r\n找整体方向 → 拆真实产品的结构和流程 → 补 Hero 、导航、CTA 等局部细节。\r\n\r\n![我的设计参考工作流]( https://i.imgur.com/skzWB5r.png)\r\n\r\n## 1. 找整体方向\r\n\r\n- [Recent]( https://recent.design/)  \r\n  每天更新网页、品牌、字体和动效案例。还没有明确方向时，我通常先逛这里。\r\n\r\n- [Lapa Ninja]( https://lapa.ninja/)  \r\n  Landing Page 灵感库，可以按行业、风格、颜色和建站工具筛选。\r\n\r\n- [Land-book]( https://land-book.com/)  \r\n  商业网站和作品集比较多，整体质量比较稳定。\r\n\r\n- [Awwwards]( https://www.awwwards.com/)  \r\n  适合找视觉创意和高完成度动效，但有些案例离真实产品比较远，不太适合直接照搬。\r\n\r\n## 2. 拆产品 UI\r\n\r\n- [Mobbin]( https://mobbin.com/)  \r\n  收录真实 App 和 Web 产品的界面及完整流程，做产品设计时非常实用。\r\n\r\n- [Refero]( https://refero.design/)  \r\n  可以按页面和组件查找真实产品 UI ，尤其适合 SaaS 产品。\r\n\r\n这两个站更适合在确定视觉方向之后，用来验证真实产品是怎么组织信息和流程的。\r\n\r\n## 3. 抠局部细节\r\n\r\n- [Design Spells]( https://designspells.com/)：细节交互、动效和彩蛋\r\n- [SupaHero]( https://supahero.io/)：网站 Hero 和首屏设计\r\n- [Navbar Gallery]( https://www.navbar.gallery/)：导航栏和菜单\r\n- [CTA Gallery]( https://www.cta.gallery/)：CTA 、转化区块和文案\r\n- [Footer]( https://www.footer.design/)：Footer 设计\r\n\r\n## 4. 找实验感\r\n\r\n- [Loadmo.re]( https://loadmo.re/)  \r\n  收录比较大胆、非常规、有实验感的移动端网站，适合找一些不一样的设计思路。\r\n\r\n如果只能留下 3 个，我会选 Recent 、Mobbin 和 Design Spells：一个找方向，一个拆真实产品，一个补细节。\r\n\r\n你会留下哪 3 个？\r\n\r\n另外也想听听大家对 Awwwards 的看法：它对真实项目到底是启发更多，还是干扰更多？有漏掉的宝藏网站也欢迎直接贴链接，我整理后补到楼里。"
