## Leg 2026-11-17 — agent-desktop: the screen read as a tree of text, not as a picture (row w077) <!-- CEO-OK: tab-rows-placed-on-the-board-by-the-next-session-2026-11-17 -->

On his word <!-- CEO-OK: tab-rows-placed-on-the-board-by-the-next-session-2026-11-17 --> (row w077 of the 24 Sep - 16 Nov WhatsApp tab, "Dene"). Read at the source 2026-11-17; not installed.

- **What it is.** `vercel-labs/agent-desktop` v1.3.1 (2026-11-13), Apache-2.0, 24,873★: one binary that reads an application's accessibility tree (AT-SPI on Linux) as JSON and gives every clickable element a ref bound to that snapshot. The loop: `agent-desktop snapshot --app <name> -i` → `agent-desktop click @s8f3k2p9:e8` (or `type`, `set-value`) → snapshot again; a stale ref is refused. No model inside. `agent-desktop mcp` serves every command as an MCP tool over stdio.
- **What it is for here.** `operator` takes a full screenshot at every step; a tree of text costs far less per step and tells the element's name. And it answers this row's open part: through its MCP the holding's agents reach the same hands.
- **Recipe.** `npm install -g agent-desktop`, then `agent-desktop status`. Needs Ubuntu 24.04+ (this machine: 26.04.1, GNOME 50.1), a running AT-SPI bus in the signed-in session, Mutter's RemoteDesktop for keys on Wayland (what `operator` already uses), `wl-clipboard`. No account, no money. Scanned first like every third-party tool.
- **Its own limits on Wayland (its Linux page).** Double-click, hover, drag and raw mouse moves answer `ACTION_NOT_SUPPORTED`; window focus and window control are not supported; a screenshot asks the portal's consent the first time. Chromium and Electron give their tree only when started with `--force-renderer-accessibility`. Its examples ran on X11/Xvfb — GNOME Wayland is not shown there.
- **The trial.** On this machine: how full the tree comes for VS Code and for Chrome (with and without the flag); the hand-over's steps (open a terminal in the editor area, paste, Enter) done with it and with `operator`, steps and tokens counted side by side; one run through its MCP from a second session. It stands beside `operator`, which stays the hand for what the tree cannot do (drag, hover, a window's focus). A snapshot carries what is on the screen: it is not written into logs.
- **What stops at him.** His word to install.
- **Source.** `.planning/research/watch-links/2026-11-16-whatsapp/` row w077.
