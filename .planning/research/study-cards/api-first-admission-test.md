## The rule

Before any row may leave **STUDY**, it answers one question in its Notes:

> **Can an agent drive this without a human at a browser?**

- **Yes → it may become a part of the operating system.**
- **No → it is admissible only as a *human tool for a named person*, never as an OS part**, and the row must say which it is.

## Why it was written

Source 38 handed the holding five programs. **Four of the five cannot be driven by anything this holding builds** — PagePilot publishes no API, Sell The Trend publishes no API, Kalodata's API is Enterprise-tier-only, and ChatGPT's seats are a human product (its API is a separate purchase this holding already declines in favour of LiteLLM). Until this rule, the tracker had **no column that would have caught that**, and a row could have reached INSTALL on the strength of a good demo.

This holding's whole product is **anti-baby-sitting**: one human who states intent and approves what faces outward. A subscription a person must log into to use is, by construction, the thing that product exists to remove.

## Where it lands

One sentence added to `INTEGRATION-TRACKER.md`'s Status-legend paragraph, and the answer written into the Notes cell of every row that has not yet reached EMBED. Needs no install and no purchase.
