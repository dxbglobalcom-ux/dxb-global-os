### 2.2 Design — measured from native pixels (frame `t051`)

- **Composition: the workforce owns the centre and the wires are given the width of a rail.**
  Panel edges by column-projection at luminance > 100: `CHANNELS` **197→350 px (153)** · `J.A.R.V.I.S.`

  drawing **723 px** — middle **34.2 %**, each rail **21 %**, and **each empty wire 86 px ≈ 12 %**.
  A connection here is an object with its own real estate, not a hairline between boxes.
- **Grammar: every row on the page is the same two-part sentence** — a bold name and a quiet role in
  wide-tracked small caps (`TOM · DEVELOPER`, `SLACK`, `META ADS`), so an employee, a channel and a
  tool are read with one habit. Chips are identical pills; only the rail's kicker says which kind.
- **Colour: one blue family, brightness the only variable** — ground `#212665`, chip fills
  `#205DDF`, and near-white (`#A3FFFF`) spent only on lettering. Same rule as 18/19, and dark-only:
  this source shows no second theme.
- **Ornament that carries no data:** corner brackets, the faint grid behind the stage, the four
  state chips and the bottom readouts. They make a web page read as an instrument.

## 3. Capabilities — the mechanism this film hands over

1. **The system can draw itself, and the drawing is a page of the product** — not a slide, not a
   Figma export. Same header, same clock, same chrome as the working wall; it is a view of the OS.
2. **A spoken sentence chooses the view.** Question → picture in **2.2 s**, and the picture lands
   **before** the spoken answer, so the voice explains what is already on the wall.
3. **Four layers, in the order work travels:** channels (how the human arrives) → the mesh (who does
   it) → the reasoning core (what thinks) → tools (what it acts on). The layer boundary is where the
   lane is defined: *each agent has its own context and skills, and its own tools*.
4. **The employee's lane is written on the employee.** Five agents, five roles, one shared context —
   printed as `5 AGENTS · SHARED CONTEXT` on the box that holds them.
5. **The tool shelf is named, and it is the business's own accounts** — publishing, advertising,
   mail, calendar, drive and **Stripe**, i.e. the money leg is a row on the same shelf.
