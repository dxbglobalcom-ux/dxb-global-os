| S2 — <title> | — | 3 [L0077, L0078, L0079] | <what tips this row> [L0077] |

Build it this way — every Turkish word above stands exactly as written; each <…> is yours to fill:
- One table. The first column is `Alt soru`; then ONE column per subject the question compares, named as
  the question names it (`Astra 6`, `Fable 5.1`; a third only when the question names a third); the last
  column is `Öne çıkan gerekçe`.
- One row per sub-question of the `ALT SORULAR` block, in its order, its first cell `S<n> — <title>` as the
  block writes it.
- A subject's cell: how many rows speak for that subject on that sub-question, then every id it counts —
  `17 [L0042, L0107, …]` holds seventeen ids. No row: `—`.
- `Öne çıkan gerekçe`: what tips the row, in at most eight Turkish words, with the ids it stands on.
- The last row is `Toplam`: each subject's column summed, a plain number, and `—` in its last cell. It cites
  NO id.
