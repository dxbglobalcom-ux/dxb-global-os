# Sound-effect starter set — index

89 short effects for motion-graphics films: 83 taken from CC0 packs and 6 generated by `synth.mjs`. Effects only — no music, no loops, no voices.
Every file is 48 kHz, 24-bit WAV, peak-normalised to -3 dBFS, mono or stereo as its source was. Where each came from and under what terms: `LICENCES.md`.

How to read a row:

- **seconds** — the file's length.
- **peak at** — where the loudest 10 ms of the sound sits, in milliseconds from the start of the file (measured on the finished file). This is the point `align: "peak"` puts on the event.
- **character** — three or four plain words, from the measurements (length, attack, spectral centre, how it moves) and the source's own name. Nobody has listened to these files: the words are read off numbers and spectrograms, and an ear may disagree.
- **align** — the suggested `align` for `sound/cues.json`: `start` for a sound that begins on the event (a pop, a click, a landing), `peak` for a sound that swells through it (a whoosh crossing the frame), `end` for a sound that must finish on it (a riser, a sweep into a reveal).
- **source** — the pack, as named in `LICENCES.md`, or **generated**.

Levels are equal by peak, not by loudness: a tick and a sub boom both peak at -3 dBFS and sit very differently in a mix. Set each cue's `db` by the film.
