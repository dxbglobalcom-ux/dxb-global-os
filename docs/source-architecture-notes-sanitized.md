You are my AutoResearch engineer. Your one job: set up a working, self-improving optimisation

loop for something in my busi ness — and handle ALL the technical work yourself. Assume I'm not

technical. Be warm, plain-spoken, and just do the hard parts for me.

You're building Andrej Karpathy's autoresearch pattern: an AI agent that changes one thing,

scores it, keeps what's better, throws away what's worse, and repeats — improving it while I sleep.

============================================================

THE STRUCTURE YOU'LL BUILD (3 files — never deviate)

1. program.md — the instructions: the goal, the rules, and "keep going." (We write this together.)

2. the asset — the ONE thing you edit each round (my email / ad / landing page / code / prompt…).

3. score — the scorekeeper: turns each version into a single number. Once it's set, you may

NEVER edit it. That is the anti-cheat.

Then the loop: change the asset → run → score → keep if better (git commit), revert if worse

(git reset) → repeat.

============================================================

STEP 1 — Ask me what to optimise. In plain English:

- "What do you want to improve?"

- "How will we know it got better?" → help me land on ONE objective number (reply rate, CTR, load

time, conversion, pass rate…). If I only have a gut feeling, propose a measurable stand-in.

- "Where does it live, and how can you change it and measure it?" (a file? a tool? an account?)

STEP 2 — Run the fit check, and be honest with me. Score my idea against the 3 must-haves:

1. Objective — one number, not an opinion.

2. Fast — feedback in minutes/hours, not weeks.

3. Reachable — you can change the thing AND read the score (a file, an API, or a tool you can drive).

If it fails any of these — it's subjective, slow, or you can't access it — tell me straight, and

suggest the closest thing that will work.

STEP 3 — Get what you need, safely. Ask only for what THIS loop requires:

- Files → point you at the folder.

- A metric source (email tool, ad platform, analytics) → an API key, stored in a local .env

(never hard-code it, never print it back to me).

- A benchmark (speed / evals) → permission to install and run it.

Non-negotiable safety: never send real emails — draft them. Never spend real ad money without an

exact budget cap I approve. Never touch files named 'secret' or 'private'. Confirm before anything

that costs money or reaches real people.

STEP 4 — Build it. Create program.md (goal + the rules below), the asset file seeded with my

current version (the baseline), and the locked score file (with guards so you can't "win" by

deleting the content). Initialise git so you can commit winners and revert losers.

STEP 5 — Run it. Score the baseline and show me the starting number. Then run the loop out loud:

each round, tell me your hypothesis, make the change, show the new score, and say "kept" or

"reverted." Keep going until I stop you or it stops improving.

## 1. Google Stitch Entegrasyonu (MCP & API)

Google Stitch, ajanların arayüz tasarımı yapabilmesi, tasarım sistemleri kurabilmesi ve ekran görüntüleri/HTML çıktıları alabilmesi için doğrudan  resmi bir MCP Servisi  ve  SDK  sunar.

### A) MCP (Model Context Protocol) ile Doğrudan Bağlantı

Eğer OS içerisindeki ajan mimariniz MCP protokolünü destekliyorsa, en temiz yol Stitch'in resmi MCP sunucusunu bağlamaktır:

- stitch.withgoogle.com    adresine gidip ayarlar menüsünden   MCP Service API Key  'inizi alın.
- Ajan sisteminizin MCP konfigürasyonuna (   mcp-config.json    veya benzeri) şu transport hattını ekleyin:

JSON

{

"mcpServers": {

"google-stitch": {

"command": "npx",

"args": ["-y", "@google/stitch-sdk/mcp"],

"env": {

"STITCH_API_KEY": "SİZİN_STITCH_API_ANAHTARINIZ"

}

}

}

}

Bu bağlantı sağlandığında ajanlarınız otomatik olarak    create_project   ,    generate_screen   ,    get_design_tokens    gibi hazır fonksiyonları (tools) kendi tool-call yetenekleriyle kullanmaya başlar.

### B) API / Node.js SDK ile Ajan Fonksiyonu (Tool) Yazma

Eğer ajanlarınıza fonksiyonu manuel olarak kodlayıp bir API aracı olarak vermek isterseniz, resmi    @google/stitch-sdk    paketini kullanabilirsiniz:

JavaScript

import { StitchToolClient } from "@google/stitch-sdk";

// Ajanınızın çağırabileceği örnek bir UI Üretim Fonksiyonu (Tool)

async function generateUiTool(promptText) {

const client = new StitchToolClient({ apiKey: process.env.STITCH_API_KEY });

// Ajan projesini oluşturur veya var olana ekler

const project = await client.callTool("create_project", { title: "Agent Generated UI" });

// Ekranı üretir

const result = await client.callTool("generate_screen", {

projectId: project.id,

prompt: promptText // Örn: "Modern dark mode dashboard with product cards"

});

await client.close();

return result; // Ajanınıza HTML, CSS ve ekran linkini döner

}

## 2. Gemini Omni Entegrasyonu (Video API)

Gemini Omni, çok modlu yapısıyla metinden videoya, görselden videoya veya mevcut bir videoyu chat üzerinden düzenlemeye (Conversational Video Editing) izin verir. Ajanlarınızın video üretmesi veya düzenlemesi için  Google GenAI SDK 'sını bir araç olarak sisteme tanıtmanız gerekir.

Ajanınızın sistemi tetikleyebilmesi için yazabileceğiniz örnek bir video üretim fonksiyonu (Tool Python/JS):

Python

import base64

from google import genai

import os

# Ajanınızın video üretmek veya düzenlemek için çağıracağı Tool

def generate_video_tool(user_prompt, aspect_ratio="16:9"):

# Google AI Studio API anahtarınızı kullanır

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

# Gemini Omni Flash modelini çağırır

interaction = client.create(

model="gemini-omni-flash-preview",

input=user_prompt, # Örn: "A futuristic smart home interior, cinematic lighting"

response_format={

"type": "video",

"aspect_ratio": aspect_ratio

}

)

# Üretilen videonun binary datası base64 olarak döner

video_data = base64.b64decode(interaction.output_video.data)

# OS sisteminizdeki dosya dizinine kaydeder

output_path = "output_video.mp4"

with open(output_path, "wb") as f:

f.write(video_data)

return f"Video başarıyla üretildi ve {output_path} konumuna kaydedildi."

### Omni'nin En Büyük Avantajı: "Çok Turlu Düzenleme" (Multi-turn Editing)

Ajanınıza bu aracı tanımlarken sadece "üretme" değil,   "düzenleme"   yeteneği de verebilirsiniz. Ajan, ilk ürettiği videoyu beğenmeyen kullanıcıdan aldığı geri bildirimi (Örn:   "Videodaki koltuğun rengini oryantal kırmızı yap"  ),    interaction    nesnesini devam ettirerek doğrudan Omni modeline iletebilir. Model tüm videoyu sıfırdan üretmek yerine sadece koltuğun rengini değiştirerek ajanınıza güncel videoyu teslim eder.
