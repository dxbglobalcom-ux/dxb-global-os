Hi, thank you for the actionbarclone project!

When I run it using the 3.3 release on my HTC One M8, there is a thin line running horizontally through the action bar, right under the title text. See attached screenshot. Yes, I know the "real" action bar is showing, but that's because I'm running this on 3.3 which uses AppCompat, and the action bar is shown by default and I haven't bothered to hide it.

I've tried changing the source myself and for the life of me I can't figure out why that line is there. I can't get rid of it, and I can't even figure out what is causing it to be there.

I think this used to appear on 3.2 also, if that's of any help.

Do you know how I can get rid of that line?

Thank you!!!!!
