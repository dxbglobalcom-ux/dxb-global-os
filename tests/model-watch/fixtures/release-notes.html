Claude Platform release notes

September 22, 2026

  • We've launched Claude Opus 5.5 (claude-opus-5-5), a model for long-running agentic coding and knowledge work. It has a 1M token context window by default, 128k max output tokens, and always-on adaptive thinking.

  • On Claude Opus 5.5, thinking can't be disabled: thinking: {"type": "disabled"} and thinking: {"type": "enabled", ...} return a 400 error. Omit the thinking field and control thinking depth with the effort parameter.

September 10, 2026

  • Claude Opus 4.8 now keeps its extended output limit on Amazon Bedrock. Nothing else changes.

August 11, 2026

  • Message Batches results are now kept for 60 days. Earlier results are unchanged.
